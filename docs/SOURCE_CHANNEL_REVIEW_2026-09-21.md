# 官员信息查询渠道：DeepSeek 建议核查

核对日期：2026-09-21。线索来自用户提供的三段 DeepSeek 回答；本记录将渠道建议与本轮查证结果分开。**入口存在，不等于信息完整、及时或准确；收录入口也不表示已接入爬虫。** 人物、职务和学历没有因这次渠道整理自动更新。

常用入口已补入 [source-catalog.json](../data/source-catalog.json)，实际取证流程见[来源维护指南](SOURCE_SEARCH_METHODS.md)。商业产品另列为待评估。以下“本轮可读”指研究工具获得正文；搜索索引可见而直连失败的页面会明确说明，不能当作实时名册。

## 先按具体职务找渠道

| 要查什么 | 优先顺序 | 核对重点 |
| --- | --- | --- |
| 济宁党务干部、省管干部的调整 | 济宁组织部、山东省委组织部发布 → 任职宣布或正式公告 → 任职单位 | 任前公示是拟任；党委职务和行政职务分开 |
| 市政府副秘书长等政府任免岗位 | 市政府人事通知、统一政策平台 → 单位领导页 | 看正文由谁决定、任免哪个具体岗位 |
| 市政府组成部门局长 | 市人大常委会决定 → 市政府公布通知 → 部门领导页 | 政府网站发布不表示政府自行决定任命 |
| 市长、法院院长等 | 本级人大选举、辞职公告；闭会期间查常委会代理职务决定 | 正式正职与代理正职分开；个别副职的闭会期间任免另核 |
| 国务院各部部长 | 全国人大或其常委会决定 → 国家主席令 → 部委官网 | 按职务查，不按“部长级待遇”推定任免机关 |
| 副部长、部长助理等 | 国务院任免通知／公报 → 部委个人页 | 党组职务单独查；决定日期、新闻日期、公报刊载日期分别记录 |
| 驻外大使 | 外交部“大使任免” → 主席任免公告 → 使馆简历 | 干部司承办具体工作，不等于干部司作出法定任免决定 |
| 司局级及地方部门负责人 | 单位人事公告、组织机构、领导分工 → 正式任免材料 | 人事栏目未必完整；旧领导页可能未同步 |
| 学历、学位和早年履历 | 官方完整简历、任前公示 → 有出处的权威人物库 → 追查百科引用 | 核准同名身份；学历、学位、全日制／在职、党校教育分别保留 |

制度依据：[现行宪法](https://www.npc.gov.cn/rdxwzx/xwzx2026/xwzx2026019/202601/t20260116_451170.html)第62、67、80、81条；[地方组织法](https://www.npc.gov.cn/rdxwzx/xwzx2026/xwzx2026019/202601/t20260116_451167.html)第11、50条。县级以上地方人大选举政府正副职和两院正职；闭会期间常委会依法决定个别副职任免、代理人选及政府组成部门负责人任免，不能把所有情形概括成“常委会表决任命”。检察长还涉及上一级批准程序，不能照搬法院规则。以上是检索路线，个案仍读对应公告。

## 一、山东与济宁

| DS 提议 | 核查结论与保留方式 |
| --- | --- |
| 山东省委组织部“鲁祖轩”微信 | **有权威报道佐证，保留。** [人民网2025-12-27刊登的省组织部公示](https://renshi.people.com.cn/n1/2025/1227/c139617-40633433.html)来源标为“鲁祖轩”；[七一网转载人民网报道](https://www.12371.gov.cn/web/article/1438307085275074560/web/content_1438307085275074560.html)明确称其为山东省委组织部微信公众号。本轮未在微信客户端检查认证主体或历史消息；不承诺所有任前公示都在这里首发。微信文章按单篇 URL 保存，不能凭空编造账号主页地址。 |
| [济宁市人民政府](https://www.jining.gov.cn/)及[统一政策文件平台](https://www.jining.gov.cn/api-gateway/jpaas-jpolicy-web-server/front/info/list) | **核心入口，修正权限表述。** 可查政府自行决定的人事事项，也可查政府公布的人大常委会任命决定。DS 将“各局局长”一概归入市政府直接任免不准确；须辨明是否为政府组成部门负责人。 |
| [济宁市人大](https://jiningrenda.jining.gov.cn/)“选举任免” | **保留。** 网站导航及任免文章可检索；本轮直连有超时。兼查人大会议选举与常委会任免、接受辞职及代理决定。不能把代理市长、正式市长、法院副院长与院长混为一种程序。 |
| [济宁市人社局](https://hrss.jining.gov.cn/) | **保留为补充。** 适合人事政策、事业单位招聘、人事考试等线索；公务员招录、遴选另查组织部／公务员主管部门。拟录用、拟聘用公示与领导干部任前公示不同，招聘名单不自动生成官员档案。本轮主页检索可见，直连有超时。 |
| 新华社、人民网、大众网、齐鲁网等 | **保留，按文章性质判断。** 它们可能转载公告，也可能发布原创采访、履历或受权消息。不能一律说“并非第一发布源头”；追踪署名、授权发布及原始文件，同稿转载不能算独立核实。 |

**一个实际容易误读的例子：**[济宁市政府公布任命市政府组成人员的通知](https://www.jining.gov.cn/art/2026/1/10/art_102110_20294.html)页面标日期2026-01-10，正文却明确是市人大常委会在2025-12-31根据市长提请决定任命城市管理局、大数据局局长，落款也是2025-12-31。[政策平台同文](https://dlrk.jining.gov.cn/api-gateway/jpaas-jpolicy-web-server/front/info/detail?iid=20294)列文号为济政任〔2025〕48号。发布网站、文号年份、页面时间均不能替代任免主体和正文决定日。DS 所举“济政任〔2026〕17号”在本记录中仅视为未核实的文号示例。

### 12380：中央与地方不能混用

DS 将中央12380称为“中管干部任前公示主要窗口”，**依据不足，予以纠正**。[中央12380的运行机制说明](https://news.12380.gov.cn/n/2013/1203/c214688-23723884.html)说明其核心是干部选拔任用监督和举报受理，本记录不将其设为任免主采集源。

部分地方12380确有公示栏目，例如本轮可直接读取的[甘肃省委组织部干部公示](https://www.gs12380.gov.cn/gbgs/index.php)。但公告里列出某省12380作为“举报网址”，不等于该网站一定发布公示。DS 提到河南、辽宁、山西等的具体首发和覆盖情况，本轮未逐一证实，留待后续；不能把甘肃实例推广到全国。`12371.cn`（共产党员网）、`12371.gov.cn`（七一网）和`12380.gov.cn`也须分别识别。

### 蒋成华的例子：任免事实与公报日期分开

[商务部个人页](https://jiangchenghua.mofcom.gov.cn/)与[新华网2026-07-31发布的人事消息](https://www1.xinhuanet.com/20260731/8f435ac48d5a4550a9abc3eb7d7a20c6/c.html)支持“任商务部副部长、免去国际贸易谈判副代表职务”。DS 说“2026年7月28日的国务院公报”，**其刊发日期表述尚未核实**。

[统战部政策库列表](https://tzb-zg.cnfin.com/zcfgk/gwywj/)的一条2026-08-21记录，摘要含2026-07-28及相同任免内容；[详情](https://tzb-zg.cnfin.com/c/2026-08-21/598201650.shtml)本轮读取失败，未定位公报原刊期号。因此7月28日可留作待核的任免日期线索，7月31日是已见新闻日期，均不能冒充已核实的公报发行日。未将这一线索自动改入人物任期。

本轮还看到商务部旧站入口与个人现页的称谓不一致，说明**官网旧模板同样可能滞后**。出现冲突时比较个人页、正式公告和有日期的具名活动，而不是只选抓取时间最新的页面。

## 四、以后怎样复用这份清单

1. **先发现，再取证。** 用聚合栏目、百科或AI定位，读到支持具体字段的正文后才写入人物资料。没有查询结果就保留未知。
2. **按字段核实。** 职务、党组身份、任期、职责、学历分别需要出处。到高校调研、参加培训或校友活动，不能直接推成毕业院校或学位。官方只写“大学”时，不补造学校、专业或全日制性质。
3. **保留来源链和日期。** 原发布机构、转载平台、决定日、发布日期、查阅日分别记录；同稿多次转载不提高独立证据数量。
4. **入口先人工试读。** HTTP 403／502、超时、空栏目、旧模板都保留访问备注；索引可见不等于直接抓取成功。未来用户补充网站时沿用[简短模板](SOURCE_SEARCH_METHODS.md#6-用户补充网站的简短模板)。
5. **待核线索不覆盖已核事实。** 公示、正式任免、目录、履职新闻分别使用。定期采集以后只生成候选变化，复核后再合并；本次未部署新的定时任务。

清单新增的`verification`描述入口核查，不能继承为人物事实状态；没有此字段的旧入口不表示本轮重查过。`commercial_pending`表示供应商待评估；`entry_kind: publisher_reference`表示账号身份／转载佐证页，不是微信账号主页。这些字段目前均未连接采集执行器。
