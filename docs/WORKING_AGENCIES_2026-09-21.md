# 中央工作机关与主页展开 · 2026-09-21

中国人民银行是国务院组成部门。金融监管总局、证监会、国家税务总局和国家统计局是国务院直属机构；国务院国资委是直属特设机构。这些分类按[国发〔2023〕5号](https://app.www.gov.cn/govdata/gov/202303/20/498124/article.html)核对，不能因为都管理经济事务就混为同一机构性质。

[国发〔2023〕6号](https://app.www.gov.cn/govdata/gov/202303/20/498123/article.html)明确，国家外汇管理局由人民银行管理，国家数据局由国家发展改革委管理。页面将它们放在主管部门下面，保留单独机构卡片。外汇局不是央行内设司，也不是国务院组成部门。

## 本轮内容

- 新增国家统计局、国家外汇管理局，补充职责、权限、来源和明确的管理关系；没有推测其完整现任领导名单。
- 补充13条有来源的机构关系、5个官方来源、11份短核对记录。2018年文件所支持的财经、深改、外事三个委员会关系使用集中统一领导措辞；不把本段未明确使用的分类术语写成原文。
- 主页在国务院下直接分组展开7个已收录组成部门、4个直属机构、1个直属特设机构，再显示外汇局、数据局两个受部委管理的国家局。并非国务院完整名录。
- 党侧展开办公厅、组织部、宣传部、统战部、政法委、派出机关和相关委员会；委员会办公室挂在各自委员会下。书记处不是这些中央工作机关的统一行政主管机关。
- 卡片显示本机构的已录入现任人员和具体职务；历史人物仍在人物库内。机关资料核对不改变人员任期、证据日期或职务状态。
- 手机和桌面都可选择“国务院机关”；视图支持直达链接、刷新和逐层返回。

## 数据与边界

公开快照为697条身份记录、333个机构、1,028段履历、516个来源编号、315份核对摘录。人员、履历和16条状态事件的内容均未因本轮机构补充而改变。未知领导人显示“现任人员待补充”。尚未核准的既有机构元数据保留，未用上级分组字段推算机构性质。

统计局职责按[官方机构职能](https://www.stats.gov.cn/jg/jgzn/)；外汇局职责与机构规格按[基本职能](https://www.safe.gov.cn/safe/jbzn/index.html)及[机构设置](https://www.safe.gov.cn/safe/jgsz/index.html)。无日期职责网页的读取日不是设立日，也不是领导任职日期。
